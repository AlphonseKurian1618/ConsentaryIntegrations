# Consentary Vault universal plugin

This directory is the single distributable source for Claude, ChatGPT, Codex, Visual Studio Code,
and standards-compatible agent integrations.

- `plugin.json` is the portable Agent Plugins 1.0 manifest used by VS Code and compatible hosts.
- `mcp.json` declares the production Streamable HTTP MCP endpoint in the portable Agent Plugins
  format. OAuth remains client-managed through the endpoint metadata.
- `.mcp.json` declares the production remote MCP endpoint and OAuth scopes.
- `skills/vault-workflows/SKILL.md` is the canonical cross-provider workflow and privacy guidance.
- `.claude-plugin/plugin.json` provides Claude package metadata.
- `.codex-plugin/plugin.json` provides OpenAI/Codex package and presentation metadata.

Do not copy the skill or MCP configuration into a provider directory. Improve the shared source and
release a new package version so every host receives the same behavior.

Clients that support Agent Skills but not Agent Plugins can install only
`skills/vault-workflows/` and configure the same remote MCP endpoint separately. The skill is
instruction-only: it contains no scripts, credentials, OAuth implementation, approval logic, or
alternative route around phone consent.

ChatGPT additionally uses `.app.json`, whose production app ID was generated by registering the
remote MCP server in ChatGPT Developer mode. Keep the `apps` manifest field aligned with this file,
and never replace the real `plugin_asdk_app_...` value with a placeholder or test ID.
